# Fire Atlas

Готовый исследовательский сервис для NASA Space Apps **Flame in Freefall**: вопрос → исследования NASA PSI → доказательства и измерения → сравнение → ответ → сценарий миссии → PDF.

Фронтенд, backend, AI 1 и AI 2 объединены. Используется настоящий корпус `psi-20261115-r2`: 508 опытов, 634 доказательства, 12 выводов и 17 источников. Общий контракт — OpenAPI 1.2.0.

## Запуск всего сервиса

Нужны Docker Desktop (Linux Engine), Node.js 22.19+ и pnpm 10.28.2.

```sh
pnpm start
```

Открыть [http://127.0.0.1:8080](http://127.0.0.1:8080). Команда создаёт `.env` со случайным секретом, собирает интерфейс и API, импортирует корпус NASA, подключает поиск, ответы и серверный PDF. Предварительная сборка интерфейса и сертификаты для локального запуска не нужны.

```sh
pnpm status
pnpm logs
pnpm stop
```

Данные сохраняются в Docker volume после остановки и перезапуска.

Без ключа модели локальный стенд работает в явно помеченном режиме **ответов из подтверждённых выводов корпуса без генеративной модели** (`FA_LLM_PROVIDER=offline`). Для генерации задать провайдера, модель и ключ в `.env`, затем повторить `pnpm start`. Ключи не попадают в браузер и Git. Реальный online-режим требует ключа с доступом к выбранной модели.

## Разработка и проверки

```sh
pnpm install --frozen-lockfile
pnpm dev             # отдельная UI-демонстрация на MSW
pnpm dev:api         # UI с сервером; см. настройку proxy в инструкции
pnpm typecheck
pnpm test
pnpm build           # production без моков
pnpm build:check
pnpm test:e2e        # сценарии UI-демо
pnpm test:live       # production UI + настоящий сервис на 8080
```

[Инструкция полного сервиса](docs/service-integration.md) описывает конфигурацию, API, Python-проверки, ключ модели, хранилище и эксплуатацию. [Протокол интеграционной проверки](docs/service-acceptance.md) содержит результаты и границы приёмки.

## Структура

| Путь                                         | Содержимое                                    |
| -------------------------------------------- | --------------------------------------------- |
| `apps/web`                                   | Восемь экранов на React/TypeScript            |
| `apps/api`                                   | API, SQLite, фоновые задачи, PDF              |
| `packages/contracts`                         | OpenAPI, примеры и валидаторы                 |
| `packages/retrieval`                         | Лексический поиск и evidence bundle           |
| `packages/reasoning`                         | Ответы, применимость, проверки ссылок и чисел |
| `data/releases`                              | Неизменяемые выпуски научного корпуса         |
| `data/raw`                                   | Исходные файлы NASA                           |
| `deploy`, `Dockerfile`, `docker-compose.yml` | Сборка и единый запуск                        |
| `tests/e2e`, `tests/live`                    | Демо и интеграционные браузерные сценарии     |

Нормативная схема: `packages/contracts/openapi.yaml`; типы обновляются через `pnpm contracts:generate`. Предыдущие протоколы отдельных модулей в `docs/` сохранены как история. Актуальные инструкции полного сервиса — по ссылкам выше.
