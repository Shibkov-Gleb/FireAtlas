## 4. Исключения и ограничения

**Карантин (4 записи, не импортируются):** FLEX тест 70 и 73 (один ID 193F001 с разными числами),
FLEX тест 114 (давление 0 mmHg), SAME-R Teflon 57 (номер повторяется, в результатах нет).

**Известные ограничения:**
1. BASS-II: у 100 из 129 опытов поток меняли по ходу опыта — скорость `unusable`, тег `flow_stepped`.
2. BASS-II: исходов и скорости распространения пламени в таблице нет.
3. FLEX: константа горения (колонка «Burning rate; mm», фактически мм²/с) хранится только в доказательстве.
4. FLEX: «~6» и «~9» с в колонке времени горения не используются как числа.
5. SAME-R: размер частиц — среднее арифметическое M1/M0; другие определения диаметра — в доказательстве.
6. Уровень гравитации нигде не подставлен как 0: `not_reported`.

## 5. Правила цитирования

- Набор данных PSI цитируется по DOI: BASS-II 10.60555/4qc4-de67, FLEX 10.60555/mbq8-0451,
  SAME-R 10.60555/2np7-jv14.
- Значение из таблицы — ссылкой на доказательство строки (`locator.row_key`, например `FLEX Test # 5 (30CAL03)`).
- Цитата из документа — ссылкой на источник и страницу (`locator.page`).
- Гипотезы из описаний PSI не являются результатами и в выводы не включены.
