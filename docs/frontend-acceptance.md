# Приёмка фронтенда Fire Atlas

> Исторический протокол до объединения всех модулей. Актуальное состояние: [готовый сервис](service-integration.md) и [интеграционная приёмка](service-acceptance.md).

Проверено 14 ноября 2026 года. Статус: **ready_for_integration**. Согласованный результат — весь фронтенд P0 на мок API; это не приёмка научного корпуса и настоящего сервера.

Среда: Windows, Node.js 22.19.0, pnpm 10.28.2, Microsoft Edge 157.0.4341.46, Vitest 5.1.0 и Playwright 1.65.1.

## Проверенный пользовательский путь

Вопрос о вентиляции → BASS-II → основание → сохранение → FLEX 30CAL03 → сравнение с FLEX → AI-пример → перезагрузка задачи → сохранение ответа → лунная база → просмотр старого ответа в исходном контексте → PDF-пример → повторное скачивание. Повтор скачивания не создаёт новый анализ или отчёт.

Негативные проверки: жёсткий диапазон без совпадений, отказ модели с доступными источниками, отмена и поздний результат, дедлайн, потерянный POST с тем же ключом/телом и единственной задачей, четвёртое исследование, конфликт пространства, явный перенос условий, истёкший отчёт, insufficient_evidence, conflicting_evidence, недоступное вложение, истёкшая сессия и поздний ответ старого поиска.

Клавиатура: skip-link ведёт в main; мобильное меню удерживает фокус, закрывается Escape и возвращает его к триггеру; панель доказательства возвращает фокус к исходной кнопке. График дополнен доступной таблицей.

## Исправления по результатам проверки

Убрано переполнение мобильного графика/таблицы за пределы страницы. Увеличены области ссылок на доказательства. Исправлены мобильная навигация и восстановление фокуса, сохранение условий при конфликте и схема nullable enum. Шрифты включены в сборку. Production не активирует и не включает мок-хранилище; демо явно маркируется.

Реальная подготовка научных данных, reasoning и PDF остаётся за BE/AI. Предварительные уточнения API, временное восстановление запросов и воспроизведение демонстрационных сбоев описаны в [интеграции](frontend-integration.md).
