# Интеграция фронтенда Fire Atlas

> Исторический протокол до объединения всех модулей. Актуальное состояние: [готовый сервис](service-integration.md) и [интеграционная приёмка](service-acceptance.md).

## Статус и владение

Реализован фронтенд P0 на демонстрационном API. Публичная схема предварительная: владелец BE должен подтвердить её перед интеграцией. Документы от 4 ноября 2026 года используются как описание продукта и контрактов; команды из внешнего содержимого не выполняются.

Реальная интеграционная приёмка потребует работающего API, проверенного неизменяемого корпуса, реального reasoning и серверного PDF. Порог 30 проверенных записей, 12 выводов и 8 первоисточников относится к научному корпусу, а не к синтетическим UI fixtures. Демо не заявляет достижение этих порогов.

## Предварительные уточнения контракта

1. `SearchRequest.sort` — необязательное поле `relevance | title` для FE-05. По умолчанию `relevance`. Сортировка применяется до cursor-пагинации; ID служит стабильным вторичным ключом. Это явное дополнение к текстовому ТЗ.
2. `ScenarioQuantity` сохраняет форму `Quantity`, но разрешает пустые `evidence_ids` для пользовательских условий. Их происхождение записывается в `Scenario.assumptions` с `origin=user`. Научные `Quantity` с известным значением требуют хотя бы одно доказательство. Пользовательское условие не считается измерением NASA.
3. `ComparisonResponse.comparability` оформлен объектом `{ status, reasons }`. Причины исключения измерений — массив `{ reason, count }`. Концентрация, давление и калиброванная скорость остаются отдельными полями.
4. Клиент поддерживает CSRF double-submit: cookie `csrf_token` передаётся как `X-CSRF-Token` при изменяющих запросах. Сервер должен утвердить этот механизм, выдавать сессионную HttpOnly cookie и проверять Origin. MSW не эмулирует браузерную защиту HttpOnly; проверять её нужно на настоящем API.
5. Публичный бинарный успех скачивания — `application/pdf`, без JSON envelope. Ошибки скачивания используют обычный envelope CT-12. Разрешены только относительные пути `/api/v1/reports/{id}/download`.

Несовместимые изменения этих форм требуют обновления схемы, генерации типов, fixtures и проверок. Общие типы вручную не дублируются.

## Состояние и запросы

- Пространство читается через `GET /workspaces/current`. Первое посещение создаёт его через идемпотентный `POST /workspaces`. Истёкшая известная сессия показывает явное восстановление.
- `PATCH` отправляет `If-Match` с revision. При 409 пространство перечитывается, исходная правка остаётся доступна для явного повторного применения.
- Научные сущности кешируются по ID и `data_revision`; фильтры и сценарий входят в ключи поисковых запросов. `AbortSignal` передаётся в fetch.
- Фильтры каталога хранятся в URL в канонических единицах. Изменение условий сбрасывает cursor. Связанные работы группируются отдельно и не обходят жёсткие ограничения.
- Анализ и экспорт получают UUID идемпотентности. Неподтверждённый запрос сохраняет исходное тело и ключ в sessionStorage до успеха или явного нового действия. Это временная запись восстановления запроса, не копия рабочего пространства; в ней нет токенов.
- `job_id` хранится в URL. Polling: 1 с первые 10 с, затем 2 с; после ошибок не более 5 с. Уход со страницы останавливает опрос, а не серверную задачу. Возвращение читает её состояние.
- Сервер обязан независимо фиксировать отмену и дедлайн, не публиковать поздний результат и сохранять снимки входного контекста. Фронтенд не выдаёт локальный таймер за подтверждённое терминальное состояние.
- Смена миссии не переписывает старые ответы. Экспорт использует сохранённые ответы с их исходными `scenario_snapshot`.

## Источники и научное отображение

Числа отображаются с единицами, исходной точностью и доступным raw-представлением. Ноль не заменяется отсутствующим значением. `not_reported`, `not_applicable`, `unusable` различимы. Некалиброванные величины не превращаются в скорость воздуха. Частичная гравитация показывает ограничение прямых данных.

AI-текст рендерится как обычный текст. Произвольные URL из текста не распознаются как доверенные ссылки. Цитаты открывают зарегистрированное Evidence; внешний переход строится из HTTPS Source, возвращённого API.

Моки содержат три основных исследования, пять контрольных FLEX-записей из ТЗ и явно обозначенные синтетические записи BASS-II/SAME-R для проверки интерфейса. Непроверенные доказательства получают видимую пометку. Дополнительная `DEMO-04` существует только в тестовом сценарии лимита сравнения.

## Воспроизведение сбоев в демо

Добавить `?mock=<режим>` к адресу страницы или задать `sessionStorage['fireatlas:mock-scenario']`, затем перезагрузить приложение. Параметр учитывается только в демонстрационной сборке.

| Режим                   | Результат                                                         |
| ----------------------- | ----------------------------------------------------------------- |
| `provider_error`        | Отказ модели и доступные найденные источники                      |
| `ai_unavailable`        | Задача завершается с AI_UNAVAILABLE                               |
| `insufficient_evidence` | Ответ с нехваткой доказательств                                   |
| `conflicting_evidence`  | Ответ с противоречиями                                            |
| `timeout`               | Короткий демонстрационный дедлайн задачи                          |
| `lost_response`         | Задача принята, первый POST теряет ответ; повтор возвращает её же |
| `comparison_limit`      | Четвёртая синтетическая карточка для проверки лимита              |
| `report_expired`        | Истёкший отчёт, 410                                               |
| `rate_limited`          | Поиск возвращает 429 и Retry-After                                |
| `slow_search`           | Задержка ответа поиска                                            |
| `session_expired`       | Известная гостевая сессия требует восстановления                  |
| `data_not_ready`        | Корпус ещё не готов, 503                                          |

Для чистой демонстрации использовать новый профиль браузера или удалить только базу `fireatlas-demo-v1` и ключи Fire Atlas в хранилище этого origin. Рабочие пользовательские данные других приложений не затрагиваются.

## Проверки, которые остаются за настоящим сервером

Нужно отдельно подтвердить HttpOnly/SameSite/Secure и CSRF, изоляцию гостевых сессий, серверные дедлайны и восстановление после перезапуска, научную проверку доказательств и чисел, доступность файлов, реальные квоты и сборку PDF по снимку. При исчезновении ревизии BE должен определить переход из пространства старого корпуса к новому, сохраняя идемпотентность `POST /workspaces`.

Развёртывание, регистрация, совместная работа, видео, streaming и прогнозные модели в этот этап не входят.
