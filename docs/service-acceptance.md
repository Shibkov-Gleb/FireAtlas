## Нагрузка

Контрольный прогон: 10 параллельных сессий × 3 раунда, 30 новых поисковых запросов и 30 запусков анализа, без повторного использования предыдущих поисковых выдач. Ошибок HTTP 0. p95: каталог 0,43 с, измерения 0,87 с, создание задачи 0,75 с, поиск 3,56 с. После удаления лишнего разбора JSON при проверке ID поиск ускорился с 4,87 с до 3,56 с. Целевые 3 с NFR-03 на этой Docker-машине под данной совмещённой нагрузкой пока не достигнуты; это открытое ограничение производительности, функциональные маршруты проходят. Генеративная модель в замере не использовалась.

## Исправления при интеграции

1. Единый контракт backend 1.2 вместо предварительного frontend 1.0; генерация TypeScript без потери обязательных полей JSON Schema.
2. Объекты `Reason`, словари `{value,label}`, nullable-сценарии, счётчики исключений измерений, корректные sort/retrieval mode.
3. Настоящие материалы, атмосфера N₂/CO₂/He, зарегистрированные скачиваемые файлы источников. График по умолчанию показывает пять контрольных опытов; весь реальный корпус доступен отдельным выбором с пагинацией и не приписывает всем опытам один материал и 21% O₂.
4. Кеш индексов неизменяемых выпусков и копирование выходных объектов, проверенное тестом на мутации и изоляцию путей. Проверка существования ID читает только ключи SQLite, без разбора JSON всех опытов. Нагрузочный инструмент использует новый набор запросов на каждом прогоне.
5. Самодостаточная сборка двух образов. Включены сырьевые файлы NASA, миграции, раскладка assets, импорт P0, API и production UI. Для localhost не нужны сертификаты и заранее собранный `dist`.
6. Полный комплект кириллических шрифтов для Linux PDF и проверка шрифтов при сборке. В исходном образе не хватало `DejaVuSans-Oblique.ttf`.
7. Восстановление адреса API через Docker DNS у nginx, healthchecks, постоянное хранилище и отдельная проверка перезапуска.
8. Production-тест stub-режима явно задаёт тестируемые адаптеры и не наследует реальные адаптеры запущенного стенда.

Браузерные результаты: 7 сценариев полного набора прошли; после добавления выбора FLEX отдельно прошли 2 затронутых сценария (контрольные точки на четырёх ширинах и полный маршрут до PDF). Всего 8 различных live-сценариев проверены.

## Границы приёмки

Online-генерация через модель на этом стенде не проверялась: ключей нет. В `.env` можно включить OpenAI или Gemini; запросы выполняет сервер. Offline-режим не скрывает отсутствие модели. Публичный хостинг и домен не создавались; запущенный стенд доступен на локальном порту 8080.

В Git нет 49 МБ исходного отчёта BASS-II; SHA256 и метаданные сохранены. Недоступное вложение не мешает работе с доказательствами, источником NASA и остальным корпусом. Подробная конфигурация и команды — в [инструкции сервиса](service-integration.md).
