# Third-party resources and SI disclosure

Fire Atlas is a Neuralnauts project for NASA Space Apps 2026. This inventory accompanies the project submission. Upstream packages retain their own licenses; their official repositories and package distributions contain the applicable license text.

## SI assistance

OpenAI Codex assisted implementation, debugging, tests, integration, data-processing code, documentation, English interface text and submission materials. The presentation contains an actual application screenshot and SI-assisted text. Original NASA measurements and source files were not replaced by generated measurements. The tested default answer mode assembles reviewed corpus findings without a generative model. Optional online providers require a server-side key.

- OpenAI Codex: https://openai.com/codex/
