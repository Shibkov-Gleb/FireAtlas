# Примеры публичного API

`p0.json` содержит 36 демонстрационных запросов, ответов и ошибок. Признак `fixture=true` находится в метаданных набора, вне научных сущностей и API envelope.

Для каждого примера указаны HTTP-метод, путь, статус, имя JSON Schema и payload. Ответы включают `data` и `meta`; ошибки используют CT-12. Идентификаторы и даты фиксированы для воспроизводимости и не означают реальный запуск или научную публикацию.

Набор покрывает неизвестное давление и ноль, контрольные точки FLEX, разные методики, лунный сценарий, успешный ответ, недостаток и противоречие доказательств, отказ модели, отмену, конфликт пространства и готовый/истёкший отчёт. В реальной сессии необходимо использовать актуальные ID и ревизии сервера.

`pnpm contracts:check` проверяет бизнес-объекты и метаданные всех примеров по той же схеме, из которой генерируются типы фронтенда.
